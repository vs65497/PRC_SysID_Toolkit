## Overview

This prompt adds hardware DUT support to the toolkit via a new `DUT_MODEL =
"hardware"` option. When hardware mode is active, data collection loops in notebooks
02–04 load pre-recorded output CSVs from the filesystem instead of calling
`dut.step()`. All analysis code is completely unchanged — it receives `H` the same
way regardless of source.

A new notebook `00_hardware_signals.ipynb` generates all input sequences for every
test in notebooks 01–04, saves them to `data/hardware/inputs/`, and provides
operator instructions for recording outputs and naming the resulting files.

The shared library (`prc_toolkit/`) is not modified by this prompt.

## Change 3: Hardware output loader helper

In each of notebooks 02, 03, and 04, add the following helper function in a cell
immediately after the config/instantiation block:

```python
from pathlib import Path
import pandas as pd

def load_hardware_output(filename: str) -> np.ndarray:
    """
    Load a pre-recorded hardware output CSV from HARDWARE_DATA_PATH.

    Expected format:
      - Header row with column names h0, h1, h2, ... (one per output electrode)
      - One row per timestep
      - Values are floating-point voltage readings

    Returns H: array, shape (T, N_h).

    If the file is not found, raises FileNotFoundError with a helpful message
    directing the operator to 00_hardware_signals.ipynb for recording instructions.
    """
    path = Path(HARDWARE_DATA_PATH) / filename
    if not path.exists():
        raise FileNotFoundError(
            f"Hardware output file not found: {path}\n"
            f"Run 00_hardware_signals.ipynb and follow the recording instructions "
            f"to generate this file before running this notebook."
        )
    df = pd.read_csv(path)
    return df.values.astype(float)
```

### Helper cell

```python
def save_input(filename: str, u_seq: np.ndarray):
    """
    Save an input sequence to data/hardware/inputs/.
    u_seq: shape (T,) or (T, N_u). Saved as CSV with header u0, u1, ...
    """
    u = np.atleast_2d(u_seq) if u_seq.ndim == 1 else u_seq
    if u.ndim == 1:
        u = u.reshape(-1, 1)
    cols = [f"u{i}" for i in range(u.shape[1])]
    pd.DataFrame(u, columns=cols).to_csv(INPUT_DIR / filename, index=False)
    print(f"Saved: {INPUT_DIR / filename}  ({u.shape[0]} timesteps)")
```
